What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used to create and structure content on web pages.HTML helps developers organize text, images, links, forms, tables, and other elements on a webpage.

HTML is a fundamental technology for web development, and it is essential for anyone interested in building websites or web applications.

HTML Document Structure

Every HTML document has a basic structure that tells the browser how to read and display the webpage.

  • HTML
  • head
  • title
  • body

The head section contains information about the webpage, while the body contains the content that appears on the page.

Common HTML Elements

HTML provides many elements that can be used to organize and display different types of content.

  • Headings
  • Paragraphs
  • Links
  • Images
  • Lists
  • Forms
  • Tables
  • Buttons

Headings

Headings are used to create titles and subtitles on a webpage. HTML provides different heading levels from H1 to H6.

Paragraphs

The paragraph element is used to display blocks of text and organize written content.

Links

Links allow users to move from one webpage to another webpage or to visit an external website.

Images

The image element is used to display images on a webpage. The alt attribute provides alternative text that describes the image.

HTML Lists

Lists are useful for organizing related information. HTML provides different types of lists.

Unordered Lists

An unordered list displays items without a specific order.

HTML Attributes

HTML attributes provide additional information about HTML elements. They are written inside the opening tag and can change the behavior or provide information about an element

  • href — used with links.
  • src — specifies the source of an image.
  • alt — provides alternative text for an image.
  • id — identifies a specific element.
  • name — identifies form controls.
  • value — specifies the value of a form control.
  • type — specifies the type of an input.
